## Hard rules (never break)
- Content ONLY from her reviewer text. Never invent facts, quotes, names, numbers or page numbers. Never edit her reviewer.
- Every `<q>` and big quote (`<p class="bq">`) must match the reviewer word for word. Check before every publish:
  `ruby tools/check_quotes.rb reviewer-text/psychotherapy-chNN.txt <site>/chapters/psychotherapy/chNN.html` → 0 missing.
  (Part 1 page uses `psychotherapy-part1.txt`; 5A/5B use `psychotherapy-ch05.txt`.)
- Citations only in the page top (source chips) and on verbatim definitions/quotes. No book tags anywhere else.
- No practice questions, no case vignettes, no em dashes in her text. Simple words.
- Memory aids are ALWAYS yellow-orange (#FBF0CF / #E2932A), never the force color. Light text on dark/pink = white.
- Phone check: at 375px and 390px wide, `document.documentElement.scrollWidth` must equal the viewport width.
- Raise `VERSION` in `sw.js` on every publish (phones cache the site). Keep the robots noindex meta tags on every page.
- Ask her before deleting anything. Show her (screenshots or the live preview) before calling something done.

## How the site is built
- Plain HTML/CSS/JS, no build step. `assets/style.css` + `assets/chapter.css` (components; newest blocks at the end:
  v3 nav, v4 compact, v5 design-team look). `assets/chapter.js` (left number menu, part tabs from
  `content/subjects.js`, table re-layout, fitting scenes to the column, Recall). `assets/scenes.js` (illustrated
  therapy rooms with her characters from `assets/figures/`; bubbles placed automatically, never by hand).
- Force themes: First Force pages link ONLY `assets/force1.css`, generated by
  `ruby tools/make_theme.rb force1 css` (run from the site folder root with the tools path adjusted, or copy the script
  into the site's `.tools/`) — re-run it after ANY edit to style.css or chapter.css, and commit the regenerated file.
- Table of contents: `content/subjects.js` (parts, chapters, `page`, `tab`, `count:false` for extra pages).
